# My Community

A calm, modern community website where neighbours ask for help, offer what they can, and see their community come together. Available in English and Nepali (नेपाली), with light and dark mode.

## Features
- Simple navigation: Home, Requests, Efforts, Resources (plus Stories and Community Map)
- English / Nepali language toggle
- Light / dark theme (remembers your choice)
- Mobile-friendly with a bottom tab bar

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Deploy
Every push to `main` is built and published to GitHub Pages automatically
(Repo → Settings → Pages → Source: **GitHub Actions**, one-time setup).
